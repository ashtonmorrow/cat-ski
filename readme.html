How to play (quick start)

Press SPACE or tap the start screen to play. Steer around trees, collect flags, and use ramps to jump. You start with nine lives. Once airborne, press 1, 2, or 3 (or tap a trick button) for bonus points.

Choose a cat, mountain, and difficulty in the settings, or start with the defaults. The 9 toggle switches between nine lives and 1-life classic.

InputAction
Left/right arrows or A/DSteer left and right
Down arrow or STuck for higher speed
Up arrow or WCarve for lower speed
1, 2, 3 (in mid-air)Trick: Meow Roll, Whisker Twist, Cat Nap
SpaceStart, retry, or resume
P or EscPause or resume
RRestart the current run

On phones and tablets, drag the joystick left or right to steer, up to slow down, or down to tuck for speed. Tap the trick buttons while airborne. SWAP exchanges the joystick and button positions.

About cat-ski

Cat Ski 1989 is a free browser game inspired by SkiFree, the 1991 release that shipped in Microsoft Entertainment Pack 3 for Windows 3.0. The original presented an endless downhill ski run with trees, jumps, and an unkillable abominable yeti that eventually appeared and ended every run. Cat Ski 1989 recreates the same loop with a cat as the player character. The game includes three regional mountain themes (Alps, Rockies, Himalayas), four cat color variants, an in-air trick system with chained scoring, gold escape ramps that spawn alongside each dog wave, and a snowman that takes the role of the original yeti. Difficulty is tunable through two sliders, with four named presets for casual players.

The game ships with a 9-lives casual mode enabled by default. Each crash, dog grab, or snowman chomp consumes a life, with a brief invincibility window before the next hit registers. A top-3 leaderboard sits at the top of the page, with separate boards for 9-lives and 1-life. Each browser keeps its own saved runs. Entering a nickname is optional and only happens after a qualifying run. English and rioplatense Spanish are available in the settings.

The project is open source at github.com/ashtonmorrow/cat-ski. It was developed by Mike Lee using Claude as a coding collaborator. The game code is in one HTML file, with separate artwork, icons, and self-hosted fonts. There is no build step, framework, or game backend. A service worker caches the game assets for offline play, and saved scores stay in the browser.

Gameplay details

Before starting, the player chooses a cat color (black, tabby, calico, or orange) and a mountain theme (Alps, Rockies, or Himalayas). Both selections persist across sessions through localStorage. Changes to the cat, mountain, difficulty, dog count, or lives apply to the next run; the current run keeps its original settings and score.

The score increases with distance traveled, plus bonuses for collected flags, completed jumps, and chained tricks. Each subsequent trick within a single jump compounds the bonus, so chaining several tricks before landing produces a higher reward than performing them across separate jumps.

Dogs chase the cat down the slope. Dodge sideways, or launch from a gold escape ramp to be airborne while a dog passes. The snowman appears 20–40 seconds after the final dog wave clears. A catch costs one life; losing the last life ends the run. The snowman is the project's tribute to the original SkiFree yeti.

Difficulty is set with two sliders. Intensity (0.8x to 5x) scales speed, obstacle density, spawn cadence, and dog tracking. Dog count (1 to 10) sets how many dog waves appear before the snowman. Four named presets (EASY, MEDIUM, HARD, and INSTA DEATH) snap both sliders to canonical positions for players who do not want to tune individual parameters.

Lives mode (the 9 button on the picker row) gives the cat nine lives instead of one. Each crash, dog grab, or snowman chomp consumes a life with a brief invincibility window before the next hit can register. The leaderboard splits by mode, so 9-lives runs and 1-life runs are scored on separate boards.

How it's built

Cat Ski uses vanilla JavaScript in index.html, an HTML canvas at 360x270 scaled up with pixelated rendering, and the Web Audio API for sound. Artwork, icons, and fonts are separate files; sound is synthesized without audio files. There is no framework or build step. The source is versioned on GitHub and deployed to Vercel.

The full build story, with the game loop, the maths behind the dog chase, the palettes pulled from photographs, and the free toolchain, lives at unwoke.ninja/cat-ski/built-with-ai.

Privacy notes

Cat Ski has no accounts, signups, or email forms. It saves game settings and scores in your browser and uses Google Analytics 4 and Mixpanel as described below.

Analytics and your choice

Google Analytics 4 loads on the game and this guide to measure visits and usage. Analytics cookies are disabled until you accept the banner. With the site's current Consent Mode setup, Google can still receive limited cookieless measurements before you choose or after you decline.

The game also loads Mixpanel, with tracking opted out by default. After acceptance, it receives events such as starting or completing a run, entering the leaderboard, sharing a run, and installing the app. These include run scores, distance, duration, difficulty, and device/browser information linked to a generated device identifier. Leaderboard nicknames are not included; only the nickname's length is sent with a leaderboard event.

Your choice is saved in this browser and shared between the game and guide. Declining keeps Mixpanel tracking and Google analytics cookies disabled. Analytics tools may use their own browser storage after acceptance. To choose again, clear this site's browser data; this also removes saved scores and preferences.

Local game state

The game saves these items in this browser's localStorage:

  • Selected cat color and mountain theme
  • Difficulty slider positions and lives-mode preference
  • Audio on/off, control mode (arrows or WASD), touch mode
  • Language preference (English or Spanish)
  • Best score per intensity / dog count / lives-mode combination
  • The top-3 leaderboard for each lives mode
  • The cookie consent decision
  • The most recent name entered for the leaderboard

These game entries use the skior_ prefix. They are not synced to other devices. Some values, such as difficulty and run score, are also included in consented Mixpanel events described above.

Leaderboard

The leaderboard has separate local boards for 9-lives and 1-life mode. Your optional nickname and saved board stay in this browser; there is no shared leaderboard database. Clearing site data removes your entries. If you accept analytics, run scores and leaderboard rank can be sent to Mixpanel without the nickname. Using SHARE sends or saves a run summary through the sharing option you choose.

Third parties

Vercel hosts the site. Requests to Vercel and the analytics providers expose standard network information, including an IP address and browser headers. Fonts and artwork are self-hosted. The game has no account system, shared score database, or advertising placements.

Common questions

Is Cat Ski free?

Yes. Cat Ski is free to play, with no account, no ads, and no in-game purchases. The line on the start screen, no quarter required, is literal.

Is there a version of SkiFree you can play online?

Cat Ski is a browser tribute to SkiFree. Play on desktop or phone with no installation required. Ski downhill, dodge obstacles, land tricks, and escape dog and snowman chasers.

What is Cat Ski based on?

SkiFree, written by Chris Pirih and released in 1991 as part of Microsoft Entertainment Pack 3 for Windows 3.0. Cat Ski keeps the downhill feel and the chaser, swaps the skier for a cat and the yeti for a snowman, and adds mountain themes, mid-air tricks, and a leaderboard.

Does the snowman catch you, like the SkiFree yeti?

Yes. The snowman appears 20–40 seconds after the final dog wave clears. A catch costs a life. In 9-lives mode you can recover while lives remain; in 1-life classic, one catch ends the run.

Can I install Cat Ski and play offline?

Yes. Cat Ski is a Progressive Web App. Use the INSTALL button when available, or your browser's Add to Home Screen option. Once the game assets have been cached during an online visit, you can play offline.

What are the controls?

Left/right arrows or A/D steer; up/W slows down; down/S tucks for speed. Space starts, retries, or resumes. P or Esc pauses or resumes; R restarts. Press 1, 2, or 3 while airborne for tricks. On a phone, drag the joystick to steer, up to slow down, or down to tuck, and tap the trick buttons while airborne.
